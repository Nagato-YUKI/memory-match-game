# Checklist

## 一、游戏系统完善模块

### 计分与存档
- [ ] 实时分数板正常显示当前配对数、用时、错误次数
- [ ] 配对成功时配对数正确 +1，错误次数仅在配对失败时 +1
- [ ] 最高分与最佳用时正确写入 `localStorage`
- [ ] 刷新页面后最高分与最佳用时正确恢复并显示
- [ ] 代码中无硬编码密钥，localStorage Key 使用常量定义

### 难度选择
- [ ] 开始界面提供难度选择 UI（网格大小 4x3/4x4/6x4）
- [ ] 选择不同网格后游戏面板正确生成对应数量的卡牌
- [ ] 限时/不限时开关功能正常，限时模式倒计时正确显示
- [ ] 限时模式时间到达后触发游戏失败逻辑

### 流程控制
- [ ] 「开始」按钮正确启动游戏并计时
- [ ] 「暂停」按钮正确停止计时并锁定所有卡牌（不可点击）
- [ ] 暂停时显示暂停遮罩/提示
- [ ] 「重新开始」按钮正确重置分数、用时、错误次数、卡牌状态
- [ ] 重新开始后卡牌重新洗牌并全部背面朝上

## 二、视觉与动效模块

### AI 素材
- [ ] 至少 2 套卡牌主题（如动物、卡通）已替换默认纯色卡牌
- [ ] 卡牌背面使用 AI 生成图片或设计图案，非纯色
- [ ] 游戏背景使用 AI 生成图片或设计背景，整体美观度明显提升
- [ ] 所有图片资源路径正确，线上环境加载正常

### 动画效果（至少 2 项）
- [ ] 卡牌翻转动画流畅，使用 CSS 3D transform 实现
- [ ] 配对成功动画运行正常（如缩放+发光+锁定状态）
- [ ] 配对失败动画运行正常（如抖动后翻回背面）
- [ ] 得分飘字动画正常显示（如 +10 上浮淡出）
- [ ] 游戏胜利/失败过渡动画正常（遮罩+结果文字+操作按钮）
- [ ] 动画无卡顿、无掉帧，60fps 流畅运行

### 主题皮肤切换
- [ ] 至少 2 套主题皮肤（浅色/深色）样式已实现
- [ ] 主题切换按钮功能正常，切换后页面配色即时生效
- [ ] 主题切换后卡牌边框、背景、文字颜色相应变化
- [ ] 用户主题选择持久化（刷新后保持上次选择）

### 音效系统（可选扩展）
- [ ] 翻牌音效正常播放
- [ ] 配对成功/失败音效正常播放
- [ ] 游戏胜利音效正常播放
- [ ] 音效开关控制功能正常
