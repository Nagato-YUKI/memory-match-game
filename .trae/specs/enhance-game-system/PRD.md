## 二、功能模块

### 2.1 计分与存档系统

#### 2.1.1 实时分数板
游戏过程中，顶部（或侧边）固定区域实时显示以下信息：

| 显示项 | 说明 | 更新时机 |
|--------|------|----------|
| 当前配对数 | 已成功的配对数量 | 每次配对成功 +1 |
| 总用时 | 从游戏开始到当前的累计秒数 | 每秒更新（暂停时停止） |
| 错误次数 | 翻开两张卡牌但不匹配的次数 | 每次配对失败 +1 |
| 当前得分 | 根据计分公式实时计算 | 每次配对成功或失败时更新 |
| 历史最高分 | 从 localStorage 读取的历史最高得分 | 页面加载时读取，游戏结束后可能更新 |
| 最佳用时 | 从 localStorage 读取的历史最短完成用时 | 页面加载时读取，游戏结束后可能更新 |

#### 2.1.2 计分公式

```
最终得分 = 基础分 + 时间奖励分 - 错误惩罚分 + 难度倍率加成
```

**基础分（Base Score）**
- 每成功配对 1 对，获得基础分 100 分
- 基础分 = 成功配对数 × 100

**时间奖励分（Time Bonus）**
- 根据完成游戏的总用时计算，用时越短奖励越高
- 时间奖励 = max(0, 时间奖励基准 - 总用时(秒)) × 时间奖励系数
- 时间奖励基准与系数按难度区分（见 2.2 难度配置参数表）

**错误惩罚分（Error Penalty）**
- 每产生 1 次配对失败，扣除 10 分
- 错误惩罚 = 错误次数 × 10
- 当前得分最低不低于 0（不允许负分）

**难度倍率加成（Difficulty Multiplier）**
- 最终得分在计算完上述三项后，乘以对应难度的倍率
- 难度倍率见 2.2 难度配置参数表

**公式汇总**
```
rawScore = (matches × 100) + max(0, timeBase - elapsedSeconds) × timeCoeff - (errors × 10)
finalScore = max(0, rawScore) × difficultyMultiplier
```

**示例**
- 玩家在「中等」难度下，8 对卡牌全部配对成功，总用时 45 秒，错误 3 次：
  - 基础分 = 8 × 100 = 800
  - 时间奖励 = max(0, 120 - 45) × 2 = 75 × 2 = 150
  - 错误惩罚 = 3 × 10 = 30
  - rawScore = 800 + 150 - 30 = 920
  - finalScore = 920 × 1.5 = 1380（向下取整）

#### 2.1.3 最高分与最佳用时存档规则

**存档时机**
- 游戏状态进入 `WON`（胜利）时，立即计算最终得分并与历史最高分比较
- 若当前得分 > 历史最高分，则更新最高分
- 若当前用时 < 历史最佳用时（且大于 0），则更新最佳用时

**localStorage 数据结构**
```javascript
const STORAGE_KEYS = {
  HIGH_SCORE: 'mmg_high_score',      // 数字，默认 0
  BEST_TIME: 'mmg_best_time',        // 数字（秒），默认 Infinity 或 null
  LAST_THEME: 'mmg_last_theme',      // 字符串 'light' | 'dark'，默认 'light'
  LAST_DIFFICULTY: 'mmg_last_difficulty', // 字符串 'easy' | 'medium' | 'hard'，默认 'medium'
  LAST_CARD_THEME: 'mmg_last_card_theme'  // 字符串 'pets' | 'geometric'，默认 'pets'
};
```

**读取时机**
- 页面 `DOMContentLoaded` 事件触发后，从 localStorage 读取上述数据
- 若 key 不存在，使用默认值
- 读取失败时（如 localStorage 被禁用），静默降级，不阻塞游戏启动

### 2.2 难度选择系统

#### 2.2.1 难度配置参数表

| 参数 | 简单（Easy） | 中等（Medium） | 困难（Hard） |
|------|-------------|---------------|-------------|
| 网格尺寸（PC） | 4 × 3 | 4 × 4 | 6 × 4 |
| 网格尺寸（移动端） | 4 × 3 | 4 × 4 | 4 × 6 |
| 卡牌对数 | 6 对 | 8 对 | 12 对 |
| 总卡牌数 | 12 张 | 16 张 | 24 张 |
| 限时模式默认阈值 | 不限时 | 60 秒 | 90 秒 |
| 时间奖励基准（秒） | 60 | 120 | 180 |
| 时间奖励系数 | 1 | 2 | 3 |
| 难度倍率 | 1.0× | 1.5× | 2.0× |
| 推荐玩家 | 新手、儿童 | 标准玩家 | 挑战型玩家 |

#### 2.2.2 限时模式规则

- 开始界面提供「限时模式」开关（toggle）
- 关闭限时模式：计时器正常累计，无时间上限，游戏以全部配对完成为胜利条件
- 开启限时模式：
  - 倒计时从对应难度的限时阈值开始递减
  - 倒计时显示在分数板区域，以 `MM:SS` 格式呈现
  - 最后 10 秒时，倒计时数字变为红色并每秒闪烁一次（`opacity: 1 -> 0.5 -> 1`，周期 500ms）
  - 时间到达 0 秒时，立即触发游戏失败逻辑（状态机进入 `LOST`）

#### 2.2.3 难度选择 UI

- 开始界面（游戏未开始状态）展示难度选择器
- 提供三个按钮/卡片：简单 / 中等 / 困难
- 默认选中「中等」（与 localStorage 中 `LAST_DIFFICULTY` 一致）
- 选中项有视觉高亮（边框色变为 `--color-primary`）
- 选择后，下方显示该难度的简要说明（网格、对数、限时）

### 2.3 流程控制系统

#### 2.3.1 游戏状态机（State Machine）

```
┌─────────┐     点击「开始游戏」      ┌──────────┐
│  IDLE   │ ──────────────────────> │ PLAYING  │
│ (未开始)│                         │ (进行中) │
└─────────┘                         └────┬─────┘
      ^                                  │
      │                                  │ 点击「暂停」
      │                                  ▼
      │                             ┌──────────┐
      │      点击「继续游戏」        │ PAUSED   │
      │ <────────────────────────── │ (暂停中) │
      │                             └────┬─────┘
      │                                  │ 点击「继续游戏」
      │                                  │
      │         全部配对完成             │ 限时耗尽
      │ <────────────────────────────────┘
      │
      │                             ┌──────────┐
      │      点击「再玩一次」        │  WON     │
      │ <────────────────────────── │ (胜利)   │
      │                             └──────────┘
      │
      │                             ┌──────────┐
      │      点击「再玩一次」        │  LOST    │
      └──────────────────────────── │ (失败)   │
                                    └──────────┘
```

#### 2.3.2 状态定义与行为矩阵

| 状态 | 状态名 | 计时器 | 卡牌交互 | UI 显示 | 可执行操作 |
|------|--------|--------|----------|---------|-----------|
| `IDLE` | 未开始 | 停止 | 全部锁定 | 开始界面（难度选择 + 开始按钮） | 选择难度、选择主题、点击「开始游戏」 |
| `PLAYING` | 进行中 | 运行 | 未匹配卡牌可点击 | 游戏面板 + 分数板 + 暂停/重新开始按钮 | 点击卡牌、点击「暂停」、点击「重新开始」 |
| `PAUSED` | 暂停中 | 停止 | 全部锁定 | 游戏面板 + 暂停遮罩（半透明 + 「继续游戏」按钮） | 点击「继续游戏」、点击「重新开始」 |
| `WON` | 胜利 | 停止 | 全部锁定 | 游戏面板 + 胜利结果遮罩（统计 + 按钮） | 点击「再玩一次」、点击「返回菜单」 |
| `LOST` | 失败 | 停止 | 全部锁定 | 游戏面板 + 失败结果遮罩（统计 + 按钮） | 点击「再玩一次」、点击「返回菜单」 |

#### 2.3.3 状态转换规则

| 当前状态 | 触发事件 | 目标状态 | 转换动作 |
|----------|----------|----------|----------|
| `IDLE` | 用户点击「开始游戏」 | `PLAYING` | 1. 根据当前难度生成卡牌并洗牌<br>2. 重置分数、用时、错误次数为 0<br>3. 启动计时器（限时模式则启动倒计时）<br>4. 隐藏开始界面，显示游戏面板 |
| `PLAYING` | 用户点击「暂停」按钮 | `PAUSED` | 1. 停止计时器<br>2. 为所有卡牌添加 `pointer-events: none`<br>3. 显示暂停遮罩层 |
| `PAUSED` | 用户点击「继续游戏」 | `PLAYING` | 1. 恢复计时器<br>2. 移除卡牌锁定（已匹配卡牌保持锁定）<br>3. 隐藏暂停遮罩层 |
| `PLAYING` | 用户点击「重新开始」 | `PLAYING` | 1. 停止当前计时器<br>2. 重置分数、用时、错误次数为 0<br>3. 重新生成卡牌并洗牌<br>4. 重新启动计时器 |
| `PLAYING` | 全部卡牌配对完成 | `WON` | 1. 停止计时器<br>2. 计算最终得分<br>3. 更新 localStorage（最高分/最佳用时）<br>4. 播放胜利动画与音效<br>5. 1.5 秒后显示胜利结果遮罩 |
| `PLAYING` | 限时模式倒计时到达 0 | `LOST` | 1. 停止计时器<br>2. 锁定所有卡牌<br>3. 播放失败动画与音效<br>4. 1 秒后显示失败结果遮罩 |
| `WON` / `LOST` | 用户点击「再玩一次」 | `PLAYING` | 同 `IDLE -> PLAYING` 的转换动作（保留当前难度和主题设置） |
| `WON` / `LOST` | 用户点击「返回菜单」 | `IDLE` | 1. 隐藏结果遮罩<br>2. 显示开始界面<br>3. 游戏面板清空 |
| `PAUSED` | 用户点击「重新开始」 | `PLAYING` | 同 `PLAYING` 内「重新开始」逻辑 |

#### 2.3.4 防重复点击机制

- 翻牌动画期间（500ms），禁止点击其他卡牌
- 配对失败动画期间（总计约 1700ms），禁止点击任何卡牌
- 状态转换动画期间（如胜利遮罩淡入 400ms），禁止触发新的状态转换
- 使用一个 `isAnimating` 布尔标志位控制，动画开始时置 `true`，结束后置 `false`

## 三、非功能需求

### 3.1 性能
- 动画帧率目标 60fps，仅使用 `transform` 和 `opacity` 属性
- 卡牌容器在动画期间动态添加 `will-change: transform`，结束后移除
- 图片资源懒加载或预加载，避免游戏过程中出现加载闪烁

### 3.2 兼容性
- PC 端：Chrome 90+、Edge 90+、Safari 14+
- 移动端：iOS Safari 14+、Android Chrome 90+、微信内置浏览器（Android/iOS）
- 降级策略：localStorage 不可用时静默忽略存档功能；Web Audio API 不可用时静默忽略音效

### 3.3 安全
- localStorage Key 使用常量定义，禁止硬编码密钥或敏感信息
- 无空 `catch {}`，所有异常必须记录到控制台或抛出

### 5.1 术语表

| 术语 | 说明 |
|------|------|
| 配对（Match） | 翻开两张图案相同的卡牌，判定为一次成功配对 |
| 错误（Error / Mismatch） | 翻开两张图案不同的卡牌，判定为一次配对失败 |
| 状态机（State Machine） | 管理游戏各状态及状态间转换规则的模式 |
| 难度倍率（Difficulty Multiplier） | 根据难度等级对最终得分进行乘算的系数 |
| 时间奖励基准（Time Base） | 计算时间奖励时使用的基准秒数，超过该时间则无奖励 |
