# 记忆翻牌小游戏

## 项目介绍
一款东方风格的记忆翻牌配对网页小游戏，支持国风与和风两种主题，
包含多种难度、排行榜、成就系统、分享功能等丰富玩法。

## 在线试玩
https://nagato-yuki.github.io/memory-match-game/

## 功能列表
- 核心玩法：翻牌配对，考验记忆力
- 三种难度：简单(4×3)、中等(4×4)、困难(6×6)
- 限时挑战模式
- 国风/和风双主题切换
- 卡面皮肤解锁系统
- 实时分数板与最高分记录
- 排行榜系统（按分数/时间排序）
- 成就系统（首次通关、满分挑战、速度之王）
- 游戏分享功能（复制成绩到剪贴板）
- 操作引导（首次进入自动提示）
- 加载画面与过场动画
- 音效与背景音乐
- 暂停/重新开始功能
- 个人简历页面
- 响应式设计，支持手机端

## 技术栈
- HTML5 + CSS3 + Vanilla JavaScript (ES6+)
- CSS 3D 翻转动画
- localStorage 本地存储
- Web Audio API / HTML5 Audio
- Clipboard API
